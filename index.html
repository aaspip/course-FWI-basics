Getting started with Google Colab

  1. Sign in to your Google account and choose a notebook above.
  2. Configure the runtime. For GPU exercises, select Runtime → Change runtime type → an available GPU → Save.
  3. Connect to the runtime and run the notebook's setup cell to install its dependencies and obtain required data.
  4. Run the experiments. Use Shift + Enter to execute each cell, or select Runtime → Run all. Read the explanations and inspect the figures.
  5. Save your work. Select File → Save a copy in Drive to retain your modifications.

Review notebook code before accepting any execution warning. Free GPU access is subject to availability and usage limits.

System setup & troubleshooting

What you need

  • Google account
  • Laptop or desktop with a web browser
  • Stable internet connection

No local Python, Jupyter, or CUDA installation is needed for Colab-compatible exercises.

Common issues

  • Missing packages: rerun the setup cell.
  • GPU unavailable: use a CPU-compatible exercise or try again later.
  • Disconnected runtime: reconnect and rerun setup and preceding cells.
  • Memory errors: reduce experiment size where supported.
