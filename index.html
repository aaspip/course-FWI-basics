Getting started

  1. Sign in to Google and open a notebook.
  2. Optionally select Runtime → Change runtime type → GPU.
  3. Connect and execute cells in order, including setup and data retrieval.
  4. Save a personal copy in Drive.

All notebooks are standalone. A browser and internet connection are required. The official GeoFWI archive is approximately 2 GB; the notebooks attempt partial downloads first. If retrieval fails, retry or upload geofwi.npy to the geofwi_cache folder in Colab.
